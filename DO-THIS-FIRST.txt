 2. GO LIVE FREE = Vercel + Supabase (~20 min needs YOU)
    (cost ₹0; needs internet accounts only)
──────────────────────────────────────────────────────────────
a) supabase.com → sign up free → New project (free)
   → SQL Editor → paste ALL of schema.sql → Run  ✅ table ready
b) Put this folder on a free GitHub account (create repo, upload files)
c) vercel.com → sign up free → Add New Project → import from GitHub
   → BEFORE clicking Deploy, add 3 Environment Variables:
      SUPABASE_URL         = (Supabase → Project Settings → API → Project URL)
      SUPABASE_SERVICE_KEY = (same page → service_role key — KEEP SECRET)
      ADMIN_PIN            = (choose your own strong 4-8 digit PIN)
   → Deploy ✅ you get a free https link like sharpedge.vercel.app
d) Edit js/config.js → set these two lines, then push/upload again:
      useRemoteApi: true,
      apiBase: "/api",
      adminPin: "YOUR-PIN"   (same as ADMIN_PIN above)
✅ DONE — one shared live booking calendar + admin sees ALL bookings.
